# Building SaaTool Wails

## Prerequisites

### 1. Go 1.24+
Already installed (you have 1.24.1).

### 2. Node.js 18+
Download from https://nodejs.org/ if not installed.
```
node --version   # should print v18 or higher
npm --version
```

### 3. Wails v2 CLI
```
go install github.com/wailsapp/wails/v2/cmd/wails@latest
```
Then verify:
```
wails doctor
```
Fix any issues `wails doctor` reports (usually just WebView2 runtime on Windows, which is pre-installed on Win10/11).

---

## Dev mode (hot-reload)

```
cd saatool-wails
wails dev
```

This will:
- Auto-generate `frontend/wailsjs/` (Go → JS bindings)
- Start a Vite dev server for the React frontend
- Open the app in a native window
- Hot-reload both Go and React on changes

---

## Production build

```
cd saatool-wails
wails build
```

Output: `build/bin/saatool.exe` (Windows) or `build/bin/saatool` (Linux/Mac)

## Project layout

```
saatool-wails/
├── main.go          ← Wails entry point + embed directive
├── app.go           ← All backend methods (exposed to React)
├── logger.go        ← In-memory log capture
├── go.mod           ← Module + replace directive for ../saatool
├── wails.json       ← Wails project config
└── frontend/
    ├── index.html
    ├── package.json
    ├── vite.config.js
    └── src/
        ├── main.jsx
        ├── App.jsx       ← Routing + theme + toast system
        ├── App.css       ← All styles (dark/light CSS variables)
        └── pages/
            ├── Library.jsx   ← Book grid, import dialog
            ├── Reader.jsx    ← Tap-zone reader + AI translation
            ├── Settings.jsx  ← Grouped settings with toggles
            └── Log.jsx       ← Auto-refreshing log view
```

---

## Notes

- The `../saatool` package is referenced via a `replace` directive — keep both
  directories in the same parent folder (`saatools/`).
- `frontend/wailsjs/` is auto-generated by Wails — do not edit it manually.
- API key is stored in the app's config directory (same as before).
